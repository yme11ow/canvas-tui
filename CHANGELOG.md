# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

## [0.0.5] - 2026-10-13

### Added
- Assignments now load in the assignments tab.
- Announcements now load in the announcements tab.

## [0.0.4] - 2026-10-09

### Added
- Customizable keybindings and configuration loading.

### Changed
- Moved hardcoded colors into `theme.rs`.
- Commented out currently unused fields in the `Course`, `Tabs`, and `Module` models.

## [0.0.3] - 2026-10-09

### Added
- Modules now show up in the modules tab.
- Lists in the right pane can be scrolled.

### Changed
- Moved list logic into `list.rs`.

## [0.0.2] - 2026-10-06

### Added
- Course tabs are loaded and shown as scrolling tabs.
- README and LICENSE.

### Changed
- Course tabs are now organized.

## [0.0.1] - 2026-10-05

### Added
- Initial courses UI.
- Canvas API client integration and course management.
